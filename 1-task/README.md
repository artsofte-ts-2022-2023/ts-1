Нужно реализовать [перегрузку](https://www.tutorialsteacher.com/typescript/function-overloading) функции `normalize`:

1. Сигнатура: `first: string`, `second: number`; возвращает строку вида `{first} {second}`.
2. Сигнатура: `first: number`, `second: string`; возвращает строку вида `{second} {first}`.
